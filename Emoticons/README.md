# DC++ emoticon packs

This directory contains ready-to-use `.dcemo` packages directly beside this README. Each package
is a ZIP archive with an `info.xml` manifest and transparent PNG images. The package drop-down in
**Settings > Appearance > Emoticons** discovers these application files and `.dcemo` files placed
directly in the per-user `Emoticons` directory. Use **Reload** after adding a package while the page
is open.

The distributed packs use the same shortcuts so that changing artwork does not change typing habits.
Supported shortcuts include `:)`, `:D`, `XD`, `;)`, `:P`, `8)`, `<3`, `:(`, `:'(`, `>:(`,
`:O`, and `:/`, with common variants where appropriate.
